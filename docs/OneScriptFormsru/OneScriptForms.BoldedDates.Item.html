ВыделенныеДаты.Элемент (BoldedDates.Item) Метод

Синтаксис

Элемент(<Индекс>)

Параметры

Индекс (обязательный)
Тип: Число.
Отсчитываемый от нуля индекс получаемого элемента.

Возвращаемое значение

Тип: Дата.

Значение по указанному индексу.

Описание

Возвращает значение по указанному индексу.

Примечание

Пример

Сообщить("Элемент(0) = " + Год(Календарь1.ВыделенныеДаты.Элемент(0)));
