ФорматИзображения.Icon (ImageFormat.Icon) Свойство

Использование

Только чтение.

Значение

Тип: ФорматИзображения (ImageFormat).

Возвращает формат изображения значков Windows.

Примечание

GDI+ компонент .NET Framework не умеет записывать формат ".ico". Метод Изображение3.Сохранить("C:\444\File8.ico", Ф.ФорматИзображения().Icon) сохранит на диске файл File8.ico, но по содержимому это будет файл в формате ".png".

Пример

Icon = Ф.ФорматИзображения().Icon;
Полный пример кода 




ПодключитьВнешнююКомпоненту("OneScriptForms.dll");
Ф = Новый ФормыДляОдноСкрипта();
Форма1 = Ф.Форма();
Форма1.Отображать = Истина;
Форма1.Показать();
Форма1.Активизировать();

Icon = Ф.ФорматИзображения().Icon;

Ф.ЗапуститьОбработкуСобытий();
