Кодировка (Encoding) Конструктор

Синтаксис

Кодировка()

Параметры

Описание

Создаёт новый экземпляр класса Кодировка (Encoding).

Примечание

Новый экземпляр класса Кодировка (Encoding), инициализируется с кодировкой формата ПоУмолчанию (Default).

Пример

Кодировка1 = Ф.Кодировка();
Кодировка2 = Кодировка1.Юникод;
Кодировка3 = Ф.Кодировка().ASCII;
